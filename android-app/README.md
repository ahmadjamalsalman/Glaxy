# Galaxy IPTV Android App

This project is a lightweight Android starter app built from the IPTV activation documentation in the workspace.

## Open in Android Studio
1. Open Android Studio.
2. Choose **Open** and select the `android-app` folder.
3. Let Gradle sync.
4. Install the Android SDK if prompted.
5. Run the app on an emulator or physical device.

## Notes
- The app is designed as a modern Material 3 interface.
- The content was inspired by the data in the provided HTML file.
- If you want a fully custom app, tell me the exact screen flow and features you need.
